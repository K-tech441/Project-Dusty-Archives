# 换一本书：落地手册

目标：把一本文本（有页码、有严格陈述）接入本方案，产出一份可检查的 Lean 库与原子图。
假定已有一个可用的 Lean/mathlib 环境与一份判据检查器（见架构文档 L5）。

---

## 0. 先决条件

- [ ] PDF 有页码（扫描件可以，但要有可读的页码），能确定"印刷页 ↔ PDF 页"的偏移；
- [ ] 数学库依赖已安装（Lean 项目能 `lake build`）；
- [ ] 判据检查器可跑（能对一节做 build / sorry / 公理 / quote / 判重检查）；
- [ ] 转录工具可用（VLM-OCR），能输出"一页一文件、文件名=页码"的 Markdown。

## 1. 书配置 + 页码索引

1. **填书配置**（纯数据，格式见 [book-config.md](book-config.md)）：
   - `sources`：每本书（英文原书/中译本）的 PDF 路径、`kind`、`printed_to_pdf` 偏移、md 目录；
   - `sections[]`：每节抄两个数——英文印刷页范围、中译印刷页范围（人翻目录就能填）；
   - 填完跑校验 V1–V6，**重点是 V5：节标题所在页必须在范围内**。
2. 机械生成页码索引；抽查 3–5 个条目（节标题、首个定义、图/表）核对页号。
3. 硬规则：**之后所有页码引用只许来自索引**，禁止凭印象。

失败模式：边界页归属错（一节末页 = 下一节首页）。对策：书配置里 `heading_page_must_be_in_range`
+ 索引对每节记录"页范围"，把节标题所在页强制包含在范围内。

## 2. 转录

1. 逐页 OCR → `p####.md`（#### = PDF 页号），保留 LaTeX 原样。
2. 抽检：公式、图表、脚注、页眉页脚；确认 md 页号与 PDF 页号一致。
3. **关键位置视觉核对**：定义/定理陈述/公式密集处，直接调视觉能力看原书页确认；
   每次核对**必须留痕**（页、确认内容、结论、时间/执行者）——转录是黑箱（VLM），
   幻觉只能压低不能消除，"md ↔ 书"这一段只能靠核对 + 抽样记录来兜底。
4. 建立"条目级定位"能力（给一个原文片段/条目名 → 返回页码），供后续引用核对。

失败模式：OCR 把公式"翻译"成自然语言（不可用）；页号错位（后续全错）；
VLM 幻觉被当成原文（关键位置没核对、或核对了但没留痕）。
对策：转录里保留原始符号；页号由文件名决定，不靠 OCR 猜；
关键位置视觉核对 + 留痕；quote 判据只管"清单 ↔ md"，不假装它能验"md ↔ 书"。

## 3. 原子化（每节）

1. 读该节英文转录；列候选原子：定义 / 定理 / 编号例子，说明性段落默认不开原子。
2. 逐条填清单（一原子一行）：
   - `quote`：**直接抄** md 原文（允许省略号分段，但每段必须逐字）；
   - `label` / `statement`：短名 + 中文转述；
   - `loc` / `book_ref`：书上的位置/编号；
   - `identity_decl`：书上说法 ↔ Lean 里怎么编码（符号/口径差异写清楚）；
   - `carrier_deps`：依赖的其它原子。
3. 填一条验一条：跑 quote 校验，确认逐字命中；不要攒到最后统一验。
4. 给本章"原子口径"拍板：哪些例子开原子、哪些允许 partial。

失败模式：quote 边界拍到邻页；把"预告/过渡段"当例子；partial 被滥用成"跳过"。

## 4. 形式化（每节）

1. R 阶段（只读）：读已有 API（别重造轮子）→ Lean 声明草案 → 依赖/分块 → 风险报告 → **停**。
2. 批准后 W 阶段：**以原子为工作单位**，一次一个：
   - 写该原子的声明（大原子可拆 1–2 步）；
   - 立刻填该原子的 Lean 指针字段（names/primary/derived/witness）；
   - 跑 quote 校验；
   - 跑 LSP 诊断，确认 0 error / 0 warning；
   - 下一个原子。
3. 证明迭代：看目标（goal）→ 试 tactic（多方案）→ 查引理（本地索引）→ 落文件 → 诊断。
   不要"改文件→编译→看错"盲试。
4. 判重：内容层不要重证基底已有的事实；缺引理时可扩展基底（走基底变更规程 + 全量回归）。
5. partial：书只给部分论证/代价过高时，0 primary + witness，并在清单里写明缺什么。

失败模式：A 层陈述引用了基底外的便利引理；匿名 instance（指针登记不了）；
`.ilean` 漏记常量-free 声明（需工具兜底）；把编译错误当"定理写错了"（可能只是 API 用错）。

## 5. 收口（每节）

1. 重生成探针（源码变了就必须重跑，否则图静默错分）。
2. 填指针（模块 + 位置 + 签名哈希），确认全部带签名哈希。
3. 跑判据（含判重、quote 逐字、模块卫生），拿到绿色 verdict。
4. 双向覆盖：清单里每条原子都有声明指针；文件里每条声明都在清单里登记（无幽灵）。
5. 重算图 + 断言；更新章节进度表与术语表；提交。

失败模式：指针陈旧（源码改过没重跑）；verdict 缺失被判成"没检查"；
生成物与手工物混提交。

## 6. 每节验收清单

- [ ] 页码索引含标题页与首定义页
- [ ] 每原子 quote 逐字命中（机械校验）
- [ ] 判据全绿（build / 无 sorry / 公理白名单 / 基底提及 / 判重 / quote / 模块卫生）
- [ ] 指针全部带签名哈希；`--check` 无过期
- [ ] 双向覆盖：无未登记声明、无幽灵原子
- [ ] 图断言全过
- [ ] 章节进度表/术语表更新完毕

## 7. 换书参数清单（复制到新项目时改这些）

| 参数 | 说明 |
|---|---|
| 书配置 | PDF 路径、页码偏移、章节边界、语言 |
| 原子口径 | 哪些元素开原子；示例/说明段处理；partial 条件 |
| 转录口径 | OCR 模型、一页一文件约定、LaTeX 保真度 |
| 基底库 | 借用的库、A 层允许名字、基底扩展流程 |
| Lean 工具链 | 版本、依赖、LSP 配置、内存策略 |
| 呈现配置 | 层颜色/标签语言/默认视图/模块过滤规则 |
